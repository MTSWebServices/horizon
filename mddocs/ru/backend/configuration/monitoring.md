# Настройка мониторинга { #backend-configuration-monitoring }

Бэкенд содержит 2 эндпоинта с метриками, совместимыми с Prometheus:

- `GET /monitoring/metrics` - метрики сервера, такие как количество запросов по пути и статусу ответа, использование CPU и RAM, и так далее.

```default
# Генерируется в CI
```

- `GET /monitoring/stats` - статистика использования, такая как количество пользователей, пространств имен, HWM.

### Пример

```default
# Генерируется в CI
```
