# 2.0.0 (2026-08-12) { #2.0.0 }

## Breaking Changes

- Minimal Python version is now 3.10
- Minimal Pydantic version is now 2.0. ([#224](https://github.com/MTSWebServices/horizon/issues/224))
- Now Horizon can read configuration from `config.yml` file. ([#216](https://github.com/MTSWebServices/horizon/issues/216))

    Configuration file has higher priority than environment variables.

- Changed `admin_users` script configuration. ([#216](https://github.com/MTSWebServices/horizon/issues/216))

    Renamed environment variable `HORIZON__ENTRYPOINT__ADMIN_USERS` to `HORIZON__ADMIN_USERS`.

    Also `config.yml` has section `admin_users: [...]` to be used instead of env variable.

- Changed `logging` configuration. ([#227](https://github.com/MTSWebServices/horizon/issues/227)).

    Moved  `settings.server.logging` / `HORIZON__SERVER__LOGGING` section to `settings.logging` / `HORIZON__LOGGING`.
    Replaced logging presets `colored|plain|json` with a format used by `logging.dictConfig()`.

- Dropped `GET /monitoring/stats` endpoint.
- Dropped `user.is_active` flag from database.

## Improvements

- Speed up REST API endpoints. ([#223](https://github.com/MTSWebServices/horizon/issues/223))

    Avoid using FastAPI `dependency_overrides` feature, see [#14441](https://github.com/fastapi/fastapi/pull/14441).

- Log settings before backend is started. ([#227](https://github.com/MTSWebServices/horizon/issues/227))
